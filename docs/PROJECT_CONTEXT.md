# Overlay Editor - Project Context

## Название проекта

Overlay Editor


## Описание

Overlay Editor — профессиональный визуальный HTML-редактор для создания графических HTML-страниц, используемых как Browser Source / Web Browser Overlay внутри Unreal Engine.

Проект предназначен для создания экранной графики:

- титры;
- HUD;
- инфографика;
- плашки;
- информационные панели;
- игровые интерфейсы;
- broadcast graphics;
- виртуальные элементы интерфейса.

Редактор не является конструктором сайтов.

Основная задача — полностью заменить ручное написание HTML/CSS визуальным интерфейсом, похожим на Figma.


---

# Основная концепция

Пользователь работает только через визуальный редактор.

Он:

- добавляет объекты;
- перемещает их мышью;
- изменяет размер;
- меняет свойства;
- управляет слоями.

Редактор автоматически создаёт:

- HTML;
- CSS;
- структуру проекта;
- ссылки на ресурсы.


---

# Главный архитектурный принцип

HTML и CSS не являются источником данных.

Главный источник истины:

```
Project JSON
```

Поток данных:

```
Project JSON

        ↓

Canvas Renderer

        ↓

HTML/CSS Generator

        ↓

HTML Overlay

        ↓

Unreal Engine Browser Source
```

# Позиционирование

Используется:

```

```

Причина:

Редактор создаёт графические сцены, где требуется точное расположение элементов.

Не используются:

- flex layout;
- grid layout;
- responsive web design.

- внешние API.


---

# Правила разработки

1. Один файл — одна ответственность.
2. Один модуль — одна задача.
3. UI и бизнес-логика должны быть разделены.
4. Renderer не изменяет данные проекта.
5. Генератор HTML/CSS работает независимо от интерфейса.
6. Новые типы объектов должны добавляться через отдельные модули.
7. Архитектура должна позволять расширение функциональности.s
